# Integral Esthetic Demo

Tablet-first clickable workflow prototype for Integral Esthetic by Martha Chacón.

This is a demonstration only. It uses sample client data and does not store submitted information.

## Demo flows

- New and returning client check-in
- Digital intake and body-area selection
- Consent and touch signature
- Client profile for Martha
- Rapid treatment documentation

Built as a lightweight static site for Netlify.
